# Shared PHP includes

This folder contains shared HTML layout fragments used by the public PHP
pages:

- `header.php` renders the public site's document head, navigation, and
  shared CSS references.
- `footer.php` renders the shared footer and closing page markup.

Keep references to shared images and styles rooted at the repository
document root so they work on localhost and on the test subdomain. Update
the root README if shared runtime requirements or setup steps change.
